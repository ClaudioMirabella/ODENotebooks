# MATH 331 - Differential Equations: notebooks that run in the browser

Interactive notebooks for a first course on ordinary differential equations, written to be used by
students who have **never programmed**. They run in the browser (JupyterLite): nothing to
install, no account, and nothing leaves the student's computer.

The course text is J. Lebl, *Notes on Diffy Qs: Differential Equations for Engineers*, free on
LibreTexts; the notebooks follow its sections and reproduce its examples.

## For students

Open the course site (your instructor gives you the address) and start with **00 - Start here**:
five steps and ten minutes of practice. The guide is also inside every notebook: run
`ol.guide()` in a cell.

## What is here

| Folder | Content |
|---|---|
| `notebooks/` | the notebooks (`00` is the student guide, `08` the first lesson in Python, the others follow the lecture plan; `NNE` are optional "going further" notebooks), the course library `odelib.py`, and its tests |
| `notebooks/plans/` | each notebook is generated by a script, `make_NN.py` (edit the script, not the `.ipynb` file); `NN_..._plan.md` is the design of the notebook, with the sources of every example |
| `site/` | builds the student site from the notebooks (`build_site.py`), serves it locally (`serve_site.py`), and runs every notebook in a real browser (`check_site.py`) |
| `.github/workflows/site.yml` | builds the site and publishes it with GitHub Pages at every push to `main` |

Every notebook has the same parts: theory in brief; worked examples from the books, done by hand
and then checked by the computer; pictures, each described in words; sliders, each with a
question to answer first; exercises in four steps (predict; by hand, then check; fill in;
explore), checked without showing the answer.

## For instructors

**Publish the site.** In the repository settings, under *Pages*, choose *GitHub Actions* as the
source. Every push to `main` then builds and publishes the site (about five minutes). Its address
is shown in the *Actions* tab and in the settings.

**Build and try it on your computer** (Python 3.12):

```
cd site
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements-site.txt      (Linux, macOS: .venv/bin/python)
.venv/Scripts/python build_site.py
.venv/Scripts/python serve_site.py                                 (then open http://localhost:8000)
```

`serve_site.py --lan` serves the site to the laptops of a classroom without internet.

**Work on the notebooks** (conda):

```
conda env create -f environment-student.yml
conda activate math331
pip install pytest nbclient nbformat ipykernel
cd notebooks
python -m pytest                      (about two minutes: the library against the books, and every notebook)
python plans/make_10.py               (rebuilds notebook 10 from its script)
```

**Correct a notebook after the students have started.** A browser that has run a notebook keeps
its own copy and goes on showing it. To make a correction reach everybody, raise the revision of
that notebook in `site/revisions.json` and push: the notebook is published under a new name, the
links are updated, and the home page says what changed. See the text at the top of that file.

**What a correct answer is.** `ol.check` compares numbers, `ol.check_formula` formulas,
`ol.check_solution` substitutes a formula in an equation; none of them shows the answer. Final
answers are at the end of each notebook, closed.

## What is not here

The books are not in this repository. Lebl's text is free on LibreTexts; the other books cited in
the notebooks are in libraries. Exercise statements quoted from them are cited where they appear.
